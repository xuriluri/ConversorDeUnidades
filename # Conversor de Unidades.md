# Conversor de Unidades 

Um projeto simples e funcional em Python para converter unidades de **temperatura** e **distância**.

---

#  Funcionalidades

- **Temperatura**:
  - Converter Celsius para Fahrenheit.
  - Converter Fahrenheit para Celsius.
- **Distância**:
  - Converter Quilômetros para Milhas.
  - Converter Milhas para Quilômetros.

---

#  Como usar

1. Certifique-se de ter o **Python 3.x** instalado em sua máquina.
2. baixe o arquivo `ConversordeUnidades.py`.
3. Execute o programa no terminal:
   ```bash
   python ConversordeUnidades.py
   ```
4. Escolha a unidade que deseja converter:
   === Conversor de Unidades ===
   1. Converter Celsius para Fahrenheit
   2. Converter Fahrenheit para Celsius
   3. Converter Quilômetros para Milhas
   4. Converter Milhas para Quilômetros
   5. Sair
   Escolha uma opção (1/2/3/4/5): 1
   Digite a temperatura em Celsius: 25
   25.0°C equivalem a 77.00°F
